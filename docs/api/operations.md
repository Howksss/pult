# Ресурсы и операции API v1

Таблица собрана из [openapi.yaml](openapi.yaml) скриптом `backend/scripts/api_operations.py`, тест `test_operations_table_matches_contract` следит, чтобы она не отставала. Пути даны от `/api/v1`. Тела ответов и примеры — в [документации Redoc](redoc.html).

Коды: 400 — тело не JSON; 401 — нет сессии, ключа или токена; 403 — роли не хватает; 404 — объекта нет или он в чужом проекте; 409 — нарушена уникальность; 422 — запрос не прошёл проверку по схеме; 500 — непредвиденная ошибка. Все ошибки — `application/problem+json` (RFC 9457).

## Проекты и участники

| Операция | Что делает | Фильтры и пагинация | Доступ | Коды ответов |
|---|---|---|---|---|
| `GET /projects` | Проекты пользователя с ролью | `limit`, `offset`, `role` | сессия или ключ | 200, 401, 422, 500 |
| `POST /projects` | Создать проект: создатель становится владельцем |  | сессия или ключ | 201, 400, 401, 403, 409, 422, 500 |
| `GET /projects/{project_id}/members` | Участники проекта | `limit`, `offset`, `role` | сессия или ключ | 200, 401, 403, 404, 422, 500 |
| `POST /projects/{project_id}/members` | Добавить участника по email (только владелец) |  | сессия или ключ | 201, 400, 401, 403, 404, 409, 422, 500 |
| `PATCH /projects/{project_id}/members/{user_id}` | Сменить роль участника (только владелец) |  | сессия или ключ | 200, 400, 401, 403, 404, 409, 422, 500 |
| `DELETE /projects/{project_id}/members/{user_id}` | Убрать участника (только владелец) |  | сессия или ключ | 204, 401, 403, 404, 409, 422, 500 |
| `GET /projects/{project_id}` | Проект: репозиторий, основная ветка и роль пользователя |  | сессия или ключ | 200, 401, 404, 422, 500 |
| `PATCH /projects/{project_id}` | Изменить название, описание или основную ветку (только владелец) |  | сессия или ключ | 200, 400, 401, 403, 404, 422, 500 |
| `DELETE /projects/{project_id}` | Удалить проект со всеми блоками, проверками и историей (только владелец) |  | сессия или ключ | 204, 401, 403, 404, 422, 500 |
